#### トマトさん（ゆうたさん）との過去トラブル

**状況**
- アモック（ツール）のサポートでやり取り
- レンさんがストレスを感じた

**原因分析**
1. **立場の問題**: ゆうたさんは「ツール提供者」→ レンさんは「お客様」意識
2. **年齢差**: 若い人に教わることへの抵抗
3. **リテラシー差**: マニュアルの理解度が低く、質問に質問で返されてイライラ
4. **防衛文言**: 最初は「決まったやり方があるわけではないんですけど」等の防御的な文章

**やり取り例（問題箇所）**
```
レンさん: 「〇〇がうまくいかないのですが、どうすればいいでしょうか？」
ゆうたさん: 「反映されないでしょうか？」（状況確認の質問）

→ レンさん視点: 「質問に質問で返すな」とイライラ
→ 実際: 前提情報がないので確認は必要だった
```

#### 対応方針

| 対策 | 詳細 |
|------|------|
| **名前を隠す** | トマトさん/ゆうたさんの名前は出さない |
| **紹介方法** | 「大岩さんと一緒にサポートするメンバー」として紹介 |
| **文章対応** | 合理的な文章より**寄り添う文言を多め**に |
| **クッション言葉** | 「情報を正しく把握するためにお伺いしますね」等を追加 |
| **権威性** | 大岩さんは「先生」として認識されているので対応しやすい |
| **2ヶ月目の引き継ぎ** | 大岩さんから丁寧に紹介してもらう |
| **平岡さんの役割** | 問題発生時はガッと抑える |

#### リスク管理

```
【チャージバックリスク】
- レンさんは複数カードで決済（限度額の問題？）
- 暴れた場合のチャージバック申請リスクあり
- 現状: 分割なし・一括払いなので軽減

【外注との相性】
- レンさんは外注が多分できない人
```


### 5.2 盛り上げ施策

#### 日報の導入（本日から）

```
【目的】
- 進捗の可視化

【方法】

- 将来的には全体共有も検討
```

#### AI×GAS小ネタ共有

**共有予定のTips**
1. **設定シートの活用**
   - コードに直接情報を書かず、スプレッドシートのセルを読み込む
   - 列を増やしてもバグりにくい

2. **プロンプトテンプレート**
   - 役割、出力形式、注意点、ルールの穴埋め形式
   - 60%程度のクオリティは出せる

3. **コメント付きコード出力**
   - ChatGPTに「一言コメントをつけて」と指示
   - 初心者でもコードの意味がわかる

4. **汎用性を持たせるテクニック**
   - マスターシートからの読み込み
   - JSON的な設定管理

## 6. 技術的な雑談メモ

### 6.1 Claude Code関連

```
【大岩の使い方】
- 短期講座の質問対応にClaude使用
- 回答の微調整は人間が行う
- 「人間の心が宿る」クオリティ

【Claude vs ChatGPT】
- Claude: 寄り添ってくれる感、押し付けがない
- ChatGPT: 冷たい、機械的

【Claude Codeの強み】
- ローカルで動く → フォルダ内容を読み書き可能
- コピペ不要
- Clasp連携でGASデプロイも自動化
- ターミナルが軽い
```

### 6.2 Clasp（GASデプロイツール）

```
【概要】
- GASコードをローカルで作成
- Webにデプロイまで自動化
- Git管理でバージョン戻しも可能

【使い方】
- Claude Codeに「Clasp使って」と言うだけ
- 自動でデプロイ、URL共有まで実行
```

### 6.3 その他ツール話

- **Gemini**: ポンコツ評価、画像生成（Nano Banana）だけ使用
- **Antigravity**: Google製AIエージェントIDE、PCが重くなる
- **Cursor**: 選択肢の一つだがClaude Codeがオンリーワン
