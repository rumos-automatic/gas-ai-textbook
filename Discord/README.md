# Discord予約投稿ツール（GAS版）

Google Apps Script（GAS）を使って、スプレッドシートに設定した内容を指定した時間にDiscordへ自動投稿するツールです。

## 📌 機能

- ✅ スプレッドシートで投稿内容と日時を管理
- ✅ 指定した日時に自動でDiscordに投稿
- ✅ 複数のチャンネル（Webhook URL）に対応
- ✅ 送信済みフラグで重複投稿を防止
- ✅ 送信日時の記録

## 🚀 セットアップ手順

### 1. Googleスプレッドシートを作成

新しいGoogleスプレッドシートを作成し、以下のヘッダー行を設定してください：

| A列 | B列 | C列 | D列 | E列 | F列 |
|-----|-----|-----|-----|-----|-----|
| 投稿日時 | 投稿内容 | Webhook URL | 送信済み | 送信日時 | 備考 |

**列の説明：**
- **A列（投稿日時）**: 投稿したい日時を入力（例：`2025-11-21 14:00`）
- **B列（投稿内容）**: Discordに投稿するメッセージ
- **C列（Webhook URL）**: Discord Webhook URL（[SETUP.md](SETUP.md)参照）
- **D列（送信済み）**: 自動で更新されます（最初は空白でOK）
- **E列（送信日時）**: 自動で更新されます（最初は空白でOK）
- **F列（備考）**: 任意のメモ（オプション）

**データ入力例：**

| 投稿日時 | 投稿内容 | Webhook URL | 送信済み | 送信日時 | 備考 |
|---------|---------|-------------|---------|---------|------|
| 2025-11-21 14:00 | こんにちは！これは予約投稿です | https://discord.com/api/webhooks/... | | | テスト投稿 |
| 2025-11-22 09:00 | おはようございます！ | https://discord.com/api/webhooks/... | | | 朝の挨拶 |

### 2. スプレッドシートIDを取得

1. スプレッドシートのURLを確認します
2. URLの中の`d/`と`/edit`の間の文字列がスプレッドシートIDです

```
https://docs.google.com/spreadsheets/d/【ここがスプレッドシートID】/edit
```

例：
```
https://docs.google.com/spreadsheets/d/1ABC...XYZ/edit
```
この場合、`1ABC...XYZ`がスプレッドシートIDです。

### 3. Discord Webhook URLを取得

Discord側でWebhook URLを取得します。詳しい手順は[SETUP.md](SETUP.md)をご覧ください。

### 4. GASプロジェクトを開く

1. 以下のURLにアクセス（clasp createで作成されたプロジェクト）
   ```
   https://script.google.com/d/1nzjrWsdeL-TjXzf373q8M0Ps-HFr2dY3fJOzg0Edk9y76XExSOWZfbR9/edit
   ```

2. または、`clasp open`コマンドで開きます：
   ```bash
   cd Discord
   clasp open
   ```

### 5. スプレッドシートIDを設定

1. GASエディタで`setupSpreadsheetId`関数を実行
2. 表示されるダイアログに、手順2で取得したスプレッドシートIDを入力
3. 「OK」をクリック

### 6. トリガーを設定

1. GASエディタで`createTrigger`関数を実行
2. 初回実行時は権限の承認を求められます：
   - 「権限を確認」をクリック
   - Googleアカウントを選択
   - 「詳細」→「（プロジェクト名）に移動」をクリック
   - 「許可」をクリック

これで、1分ごとにスプレッドシートをチェックして、投稿時刻が来ている投稿を自動的にDiscordに送信します。

## 📖 使い方

### 基本的な使い方

1. スプレッドシートに投稿内容を入力
   - A列：投稿日時（例：`2025-11-21 14:00`）
   - B列：投稿内容（例：`こんにちは！`）
   - C列：Webhook URL

2. そのまま待つだけ！
   - 指定した日時が来ると自動的に投稿されます
   - D列に「送信済み」と記録されます
   - E列に実際に送信された日時が記録されます

### 複数チャンネルへの投稿

異なるWebhook URLを使うことで、複数のDiscordチャンネルに投稿できます：

| 投稿日時 | 投稿内容 | Webhook URL | 送信済み | 送信日時 | 備考 |
|---------|---------|-------------|---------|---------|------|
| 2025-11-21 14:00 | お知らせです | https://...channel1... | | | チャンネル1 |
| 2025-11-21 14:00 | 同じ内容をチャンネル2にも | https://...channel2... | | | チャンネル2 |

### 投稿のキャンセル

投稿をキャンセルしたい場合は、以下のいずれかを実行：
- その行を削除する
- D列に「送信済み」と手動で入力する（送信されずにスキップされます）

## 🔧 管理機能

### テスト投稿

実際に投稿されるか確認したい場合：

1. `testPost`関数内の`YOUR_WEBHOOK_URL_HERE`を実際のWebhook URLに変更
2. `testPost`関数を実行
3. Discordに「これはテスト投稿です」というメッセージが投稿されます

### トリガーの削除

自動投稿を停止したい場合：

1. `deleteTriggers`関数を実行
2. すべてのトリガーが削除されます

### 再度トリガーを設定

1. `createTrigger`関数を実行
2. トリガーが再設定されます

### ログの確認

動作状況を確認したい場合：

1. GASエディタで「実行ログ」を開く
2. 以下のような情報が記録されています：
   - 投稿チェック開始/終了
   - 各行の処理状況
   - 投稿成功/失敗
   - エラー情報

## 📝 Tips

### 日時の入力形式

以下のいずれかの形式で入力できます：
- `2025-11-21 14:00`
- `2025/11/21 14:00`
- `11/21/2025 14:00`

または、Googleスプレッドシートの日時フォーマットを使用することもできます。

### 過去の日時を入力した場合

投稿日時が現在時刻より前の場合、次回のチェック時に即座に投稿されます。

### トリガーの実行間隔を変更したい場合

`createTrigger`関数内の`.everyMinutes(1)`を変更してください：
- `.everyMinutes(5)` → 5分ごと
- `.everyMinutes(10)` → 10分ごと
- `.everyHours(1)` → 1時間ごと

## ⚠️ 注意事項

- Webhook URLは第三者に知られないように注意してください
- Discordの利用規約を遵守してご使用ください
- 大量の投稿は避け、適切な間隔を空けてください
- GASの実行時間制限（1日あたり90分）に注意してください

## 🐛 トラブルシューティング

### 投稿されない場合

1. **スプレッドシートIDが正しく設定されているか確認**
   - GASエディタで「ファイル」→「プロジェクトのプロパティ」→「スクリプトのプロパティ」を確認

2. **トリガーが設定されているか確認**
   - GASエディタで「トリガー」アイコンをクリックして確認

3. **実行ログを確認**
   - エラーメッセージが表示されていないか確認

4. **Webhook URLが正しいか確認**
   - `testPost`関数でテスト投稿してみる

### 権限エラーが出る場合

1. 再度トリガー設定を実行
2. 権限の承認画面で「許可」をクリック
