# Discord Webhook URL 取得手順

このドキュメントでは、Discord Webhook URLを取得する方法を詳しく説明します。

## 📌 Webhookとは？

Webhookは、外部のアプリケーション（今回はGAS）からDiscordにメッセージを送信するための仕組みです。Webhook URLを使うことで、ボットアカウントを作成せずに簡単にDiscordへ投稿できます。

## 🚀 Webhook URL取得手順

### ステップ1: サーバー設定を開く

1. Discordを開く
2. 投稿したいチャンネルがあるサーバーを選択
3. サーバー名を右クリック（またはサーバー名の横の「∨」をクリック）
4. **「サーバー設定」** を選択

> **注意**: サーバー設定を開くには、サーバーの管理者権限または「Webhookを管理」権限が必要です。

### ステップ2: Webhookページを開く

1. 左側のメニューから **「連携サービス」** を選択
2. 上部のタブから **「Webhook」** を選択
3. **「新しいウェブフック」** ボタンをクリック

### ステップ3: Webhookを設定

1. 新しいWebhookが作成されます
2. 以下の項目を設定できます（任意）：
   - **名前**: Webhookの名前（投稿時の表示名になります）
   - **アイコン**: Webhookのアイコン画像
   - **チャンネル**: 投稿先のチャンネル

3. 設定が完了したら **「変更を保存」** をクリック

### ステップ4: Webhook URLをコピー

1. 作成したWebhookの **「Webhook URLをコピー」** ボタンをクリック
2. URLがクリップボードにコピーされます

Webhook URLは以下のような形式です：
```
https://discord.com/api/webhooks/1234567890/ABCDEFGHIJKLMNOPQRSTUVWXYZ
```

または
```
https://discordapp.com/api/webhooks/1234567890/ABCDEFGHIJKLMNOPQRSTUVWXYZ
```

### ステップ5: スプレッドシートに貼り付け

1. Googleスプレッドシートを開く
2. C列（Webhook URL列）に、コピーしたURLを貼り付け

## 🔒 セキュリティ上の注意事項

### ⚠️ Webhook URLは秘密情報です

Webhook URLを知っている人は、誰でもそのチャンネルにメッセージを投稿できます。以下の点に注意してください：

1. **公開しない**
   - GitHub、SNS、ブログなどで公開しない
   - スクリーンショットを撮る際もURLが写り込まないように注意

2. **共有しない**
   - 不特定多数の人に共有しない
   - 信頼できる人とのみ共有する

3. **定期的に更新**
   - Webhook URLが漏洩した可能性がある場合は、Webhookを削除して新しく作成する

### 🗑️ Webhookの削除方法

不要になったWebhook、または漏洩した可能性があるWebhookは削除してください：

1. Discordのサーバー設定を開く
2. 「連携サービス」→「Webhook」を選択
3. 削除したいWebhookの右側の **「削除」** ボタンをクリック
4. 確認ダイアログで **「削除」** を選択

## 📝 複数チャンネルへの投稿

異なるチャンネルに投稿したい場合は、それぞれのチャンネル用にWebhookを作成してください：

1. チャンネル1用のWebhook URLを取得
2. チャンネル2用のWebhook URLを取得
3. スプレッドシートで、それぞれの投稿にそれぞれのWebhook URLを設定

| 投稿日時 | 投稿内容 | Webhook URL | 送信済み | 送信日時 | 備考 |
|---------|---------|-------------|---------|---------|------|
| 2025-11-21 14:00 | チャンネル1への投稿 | https://...webhook1... | | | チャンネル1 |
| 2025-11-21 14:00 | チャンネル2への投稿 | https://...webhook2... | | | チャンネル2 |

## 🎨 Webhookのカスタマイズ

### アイコンと名前の変更

1. Discordのサーバー設定で該当のWebhookを選択
2. 「名前」と「アイコン」を変更
3. 「変更を保存」をクリック

これにより、投稿時の表示名とアイコンが変更されます。

### 投稿先チャンネルの変更

1. Discordのサーバー設定で該当のWebhookを選択
2. 「チャンネル」プルダウンから別のチャンネルを選択
3. 「変更を保存」をクリック

## 🐛 トラブルシューティング

### Webhookが作成できない

**原因**: 権限が不足している可能性があります

**解決策**:
- サーバーの管理者に連絡して、「Webhookを管理」権限を付与してもらう
- または、管理者にWebhookを作成してもらい、URLを共有してもらう

### 投稿が失敗する

**原因1**: Webhook URLが間違っている

**解決策**:
- Webhook URLを再度コピーして貼り付け直す
- URLの前後に余計な空白が入っていないか確認

**原因2**: Webhookが削除されている

**解決策**:
- Discordのサーバー設定でWebhookが存在するか確認
- 削除されている場合は、新しいWebhookを作成

**原因3**: サーバーから退出している

**解決策**:
- Webhookを作成したサーバーにまだ参加しているか確認

## 💡 よくある質問（FAQ）

### Q1: Webhook URLは他の人に知られても大丈夫？

**A**: いいえ、絶対に秘密にしてください。Webhook URLを知っている人は誰でもそのチャンネルに投稿できます。

### Q2: 1つのWebhookで複数のチャンネルに投稿できる？

**A**: いいえ、各Webhookは1つのチャンネルに紐づいています。複数のチャンネルに投稿したい場合は、それぞれにWebhookを作成してください。

### Q3: Webhookを使った投稿は誰が投稿したか分かる？

**A**: Webhook名とアイコンが表示されますが、実際に誰が投稿したかは表示されません。Webhook名を設定することで、誰（または何）が投稿したかを示すことができます。

### Q4: Webhookの投稿数に制限はある？

**A**: Discordには rate limit（レート制限）があります。1つのWebhookから短時間に大量の投稿をすると、一時的に投稿できなくなる場合があります。適度な間隔を空けて投稿してください。

### Q5: Webhookで画像や埋め込み（Embed）は送信できる？

**A**: はい、できます。ただし、今回のツールはシンプルなテキスト投稿のみに対応しています。画像やEmbedを使いたい場合は、Code.gsの`postToDiscord`関数を拡張する必要があります。
